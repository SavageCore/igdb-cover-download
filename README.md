# igdb-cover-download

> Userscript to a download button to IGDB game cover images for easy downloading of the high-resolution version.

![Preview](./assets/preview.png)

## Install

Click [here](https://github.com/SavageCore/igdb-cover-download/releases/latest/download/igdb-cover-download.user.js) to install with [Greasemonkey](https://www.greasespot.net/) or [Violentmonkey](https://violentmonkey.github.io/)

## Usage

Navigate to a IGDB game page and click the Download Cover button overlaying the image.
